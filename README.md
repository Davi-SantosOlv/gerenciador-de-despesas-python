# 📊 Gerenciador de Despesas com Python

Este programa é um programa com Interface em Linha de Comando (CLI) de um gerenciador de despesas pessoal. Os registros são guardados no arquivo `despesas.csv`, de tabela única. É possível visualizar o saldo do usuário, e anotar tanto gastos quanto receita. Não há uma função de exclusão para os registros.

## 📚 Conceitos praticados

- **CSV Module:** Acesso à arquivos CSV para leitura e escrita de novas linhas.
- **OS Module:** Comandos básicos que garantem que o arquivo CSV seja criado apenas quando ainda não existe.
- **Exception Handling:** Uso de `try` e `except` para validar digitações do usuário e garantir a leitura do arquivo CSV.
- **Classes:** Métodos escritos em uma classe à parte do `main`, a qual foi importada.

## 🚀 Como executar

1. Certifique-se de ter o Python instalado.
2. Clone este repositório:
   ```bash
   git clone https://github.com/Davi-SantosOlv/gerenciador-de-despesas-python.git
   ```
3. Entre na pasta do projeto e execute:
   ```bash
   python main.py
   ```
